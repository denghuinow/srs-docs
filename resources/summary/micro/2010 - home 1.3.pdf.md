**Purpose & Scope**: A prototype home management system for monitoring and controlling environmental, security, and appliance devices via a web interface, operating in a simulated environment.

**Core Functions**:
* Monitor and control home temperature and humidity via programmable thermostats and humidistats.
* Manage home security via contact sensors and alarms.
* Control the on/off state of small appliances and lighting units.

**Key Constraints**:
* The system is a prototype to be completed within twelve months.
* All development and testing must occur in a simulated environment with no physical home or devices.
* The system must use a wireless gateway with a communication range of up to 1000 feet indoors.
