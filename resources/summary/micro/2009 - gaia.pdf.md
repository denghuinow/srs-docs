**Purpose & Scope**: GOG is a software simulator to generate statistically equivalent Gaia mission catalog and main database data without using the actual telemetry or raw simulators.

**Core Functions**:
* Generate data from either a Universe Model or a user-provided object catalog.
* Simulate epoch data (per-transit astrometry, photometry, radial velocity).
* Simulate combined data (parallax, proper motions, mean parameters from all transits).

**Key Constraints**:
* Output formats must comply with the Universe Model and Main Database Interface Control Documents.
* Must process one complete source within two CPU seconds.
* Must be a standalone Java application deployable on Linux, UNIX, and Mac.
