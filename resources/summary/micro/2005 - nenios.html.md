Purpose & Scope: A web-based system to manage a child care center's daily operations, including enrollment, attendance, billing, and reporting.

Core Functions:
* Manage child and parent accounts, including enrollment, waiting lists, and authorized pickups.
* Record child attendance and generate monthly invoices with late-pickup fees.
* Generate standard reports on enrollment, immunizations, and customer information.

Key Constraints:
* The system must be a web application accessible via Internet Explorer and Netscape Navigator.
* The system must respond to all user requests within 20 seconds.
* The system must use Microsoft ASP.NET technology.
