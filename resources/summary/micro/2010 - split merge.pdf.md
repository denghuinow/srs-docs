**Purpose & Scope**: Provide a free, open-source tool for manipulating PDF files via a graphical and command-line interface.

**Core Functions**:
* Split a single PDF document by various criteria.
* Merge multiple PDF documents or extract sections from them.
* Visually reorder, rotate, and compose pages from PDF documents.

**Key Constraints**:
* Requires Java Runtime Environment version 1.6 or higher.
* Released under the GNU General Public License (GPL).
* Output file compression requires PDF version 1.5 or above.
