**Purpose & Scope**: This SRS defines requirements for the Management Processes module of an Integrated Library System, to replace and enhance reporting and analytics within the PINES consortium's existing Evergreen ILS.

**Core Functions**:
* Provide configurable query and reporting tools against all library data types (e.g., items, patrons, transactions).
* Generate standardized operational and board reports, including financial and collection analysis.
* Support inventory management, including tracking, transferring, and weeding of materials across branches.

**Key Constraints**:
* Must operate on a Linux/Solaris server and be accessible via web browser or Windows client.
* Must use a fully relational database backend.
* Must not constrain the functionality of the separate Online Public Access Catalog (OPAC) module.
