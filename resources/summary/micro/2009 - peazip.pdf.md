**Purpose & Scope**: PeaZip is a cross-platform file and archive manager providing a graphical frontend for open-source compression utilities.

**Core Functions**:
* Create and update compressed archives in multiple formats.
* Extract contents from compressed archives.
* Securely delete files and compare files byte-to-byte.

**Key Constraints**:
* Must run on x-86 compatible CPU.
* Source code modifications require LGPL license compliance.
* Drag-and-drop from application to system requires MS Windows.
