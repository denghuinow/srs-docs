Purpose & Scope: The product is a computerized puzzle game for solving a specific headache.

Core Functions:
*   Move blocks on a defined board to solve the puzzle.
*   Undo and reo the last thousand player actions.
*   Record and display player statistics (move count, time) and high scores.

Key Constraints:
*   Must run on any operating system supported by the Qt graphical library.
*   Requires a graphical display with a minimum resolution of 800x600 pixels.
*   Must be portable to the Windows OS.
