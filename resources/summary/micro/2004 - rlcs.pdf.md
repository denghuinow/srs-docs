**Purpose & Scope**: Software to replace the aging I-15 Reversible Lane Control System, enabling the opening and closing of reversible lanes for peak traffic and special events.

**Core Functions**:
*   Monitor and control the status of all field devices (e.g., gates, pop-ups, signs).
*   Execute stored operational command sequences to open and close facility entrances.
*   Provide a graphical user interface for system status, command entry, and reporting.

**Key Constraints**:
*   The system must be available 24 hours per day, 7 days per week.
*   The software must prevent opening an entrance for one direction of travel if an entrance for the opposite direction is open.
*   The application software and critical data at field controllers must reside in non-volatile memory.
