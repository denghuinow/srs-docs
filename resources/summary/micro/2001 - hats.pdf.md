**Purpose & Scope**: Provide a platform-independent graphical user interface to manage applications, execute transformations, and display outputs for the High Assurance Transformation System (HATS).

**Core Functions**:
*   Manage applications (create, select, configure).
*   Orchestrate parsing and execution of transformation language programs on target files via HATS-SML.
*   Display and navigate transformation outputs (Syntax Derivation Trees and pretty-printed text).

**Key Constraints**:
*   Must be implemented in Java and be platform-independent (run on Windows 2000, Sun Solaris, and Linux).
*   Must interface with the existing HATS-SML (version 2.0) service programs.
*   All files for a single application must reside in one directory.
