**Purpose & Scope**: The system manages heating and cooling units based on thermostat readings to control building temperature within defined limits.

**Core Functions**:
* Monitor temperature from thermostats and determine if heating or cooling is required.
* Control the activation of heating/cooling units based on utilization limits.
* Log system events and generate operational reports.

**Key Constraints**:
* The system shall run on the Microsoft Windows NT operating system.
* Heating/cooling units provide no feedback on their status to the system.
* A maximum number of heating/cooling units can be active concurrently.
