**Purpose & Scope**: A web portal for scientists to manage data and run bio-geochemical simulations using the Daymet and Biome-BGC models on grid computing resources.

**Core Functions**:
*   Manage user accounts and data objects (e.g., surface observations, site data).
*   Execute and monitor Daymet and BiomeBGC modeling runs.
*   Share and download simulation input and output data.

**Key Constraints**:
*   Must use the Globus toolkit.
*   Must integrate with the NCAR Mass Storage System for all file storage.
*   Users must have valid NCAR Gatekeeper accounts.
