**Purpose & Scope**: A network system for exchanging driver tachograph card status and assignment information between EU Member State Card Issuing Authorities.

**Core Functions**:
* Process requests to check a driver's issued tachograph cards.
* Process requests to check or modify the status (e.g., lost, stolen) of a tachograph card.
* Generate and provide usage statistics for system monitoring.

**Key Constraints**:
* The system must prevent any Member State from reconstructing a consolidated European database from the exchanged messages.
* The system must use the TESTA-II network facilities.
* The system must guarantee non-repudiation and data privacy for all transactions.
