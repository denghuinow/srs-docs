**Purpose & Scope**: Provide an object-based, application-independent framework for centralized user information management and retrieval.

**Core Functions**:
*   Maintain a centralized store for user information from specified applications.
*   Provide a hierarchical view and relationship management for stored information.
*   Expose core functionality through a public API for client applications.

**Key Constraints**:
*   Must run on hardware with a 1-GHz Pentium III and 256 MB RAM.
*   Framework shell must not use more than 40 MB of RAM.
*   Must target Windows 2000 Professional and Windows XP operating systems.
