**Purpose & Scope**: A web-accessible Publications Management System to manage a database of bibliographic information and full-text publications, with access control and automated metadata extraction.

**Core Functions**:
* Search, view, and download publications.
* Upload publications and manage bibliographic metadata.
* Administer users, groups, and system configuration.

**Key Constraints**:
* Must run on a specified Linux server (Wilma).
* Must be implemented in Ruby without using frameworks.
* Web interface must comply with W3C XHTML 1.0 Transitional standard.
