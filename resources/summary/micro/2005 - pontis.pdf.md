**Purpose & Scope**: A next-generation bridge management system for state transportation agencies, replacing Pontis 4.x to manage bridge inventory, inspection, condition assessment, and project planning.

**Core Functions**:
*   Manage bridge inventory and inspection data, including calculation of derived condition ratings.
*   Perform program simulation and bridge-level analysis to generate work recommendations.
*   Develop and manage preservation policies and project programs.

**Key Constraints**:
*   Must be developed using Microsoft .NET technologies and support specified RDBMS (Oracle, SQL Server, Sybase).
*   Must maintain consistency with and provide a migration path from the existing Pontis 4.x application.
*   Must support both connected (web) and disconnected (standalone) user environments.
