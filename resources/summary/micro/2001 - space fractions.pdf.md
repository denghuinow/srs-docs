**Purpose & Scope**
A web-based interactive game to improve fraction-solving skills for sixth-grade students.

**Core Functions**
*   Present a series of multiple-choice fraction questions within a storyline.
*   Calculate and display a user's score at the end of the game.
*   Allow an administrator to update the game's questions via a web interface.

**Key Constraints**
*   Must run in a web browser with Macromedia Flash 5 and JavaScript support.
*   All user input must be via mouse clicks; no keyboard input is required.
*   The product consists of Flash movies with a total size of approximately 1-2 MB for the main game.
