**Purpose & Scope**: Process and archive ASPERA-3 instrument telemetry and Mars Express orbit/attitude data into IDFS data sets for the science team and public archive.

**Core Functions**:
* Acquire ASPERA-3 and Mars Express telemetry data from ESOC.
* Process all science, engineering, and ancillary data into IDFS data sets.
* Submit validated ASPERA-3 IDFS data sets to the NASA Planetary Data System within six months of acquisition.

**Key Constraints**:
* System must be UNIX-based.
* Web server access must be password-protected for non-public data.
* Final data delivery mechanisms to Co-Investigators must be defined six months prior to Mars Express launch.
