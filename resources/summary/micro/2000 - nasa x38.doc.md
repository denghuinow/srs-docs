**Purpose & Scope**: Provide fault-tolerant system services for the X-38 Crew Return Vehicle's quad-redundant Flight Critical Computer, acting as an interface between application code and underlying hardware/OS.

**Core Functions**:
*   Schedule and execute cyclic application tasks at 50 Hz, 10 Hz, and 1 Hz rates.
*   Provide fault-tolerant message-passing communication services between processors.
*   Detect, isolate, and manage hardware faults to maintain system operation.

**Key Constraints**:
*   Must become operational within 1.5 minutes from power application.
*   Must be two-fault tolerant for any two non-simultaneous hardware faults.
*   Must be written in C and use the VxWorks 5.4 operating system.
