**Purpose & Scope**: To provide a robust digital repository for the long-term preservation and access of NLM's digitized and born-digital biomedical collection materials.

**Core Functions**:
*   Ingest digital materials and generate compliant Archival Information Packages.
*   Provide controlled access to repository holdings for multiple user classes.
*   Execute preservation planning to ensure long-term accessibility of content.

**Key Constraints**:
*   Must conform to HHS/NIH security and software standards.
*   Must integrate with existing NLM systems (e.g., Integrated Library System).
*   Must support multiple languages and non-Roman scripts.
