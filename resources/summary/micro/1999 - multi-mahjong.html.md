**Purpose & Scope**: A client-server Mahjong game enabling single-player and networked multiplayer play for up to four participants.

**Core Functions**:
*   Enforce Chinese Mahjong rules for all player actions.
*   Support game initiation for single-player and multi-player sessions over TCP/IP.
*   Provide computer opponents to complete a four-player table.

**Key Constraints**:
*   Must be implemented using JDK 1.2.
*   Computer opponent responses must occur within one minute.
*   The client GUI must operate within an 800x600 pixel, 16-bit color resolution.
