**Purpose & Scope**
A regional network to integrate disparate traffic management systems into a common data repository and enable device command/control across the Dallas/Ft. Worth metroplex.

**Core Functions**
*   Collect and standardize traffic data from multiple agencies.
*   Provide a web-based map displaying traffic conditions and incidents.
*   Enable remote command and status monitoring of field devices.

**Key Constraints**
*   Must utilize the ITS Traffic Management Data Dictionary (TMDD) standard.
*   Must use DATEX/ASN over TCP/IP for data transmission.
*   The server must execute in a Microsoft Windows NT environment.
