**Purpose & Scope**: Provide a 3D visualization tool for biological data to enable researchers to investigate and compare data attributes.

**Core Functions**:
* Plot data points in a 3D grid from a formatted input file.
* Allow user interaction to rotate, zoom, and move the grid.
* Display point details upon user selection.

**Key Constraints**:
* Must be available on both Windows and Linux operating systems.
* Must be ready for inclusion in a scientific paper by March 2005.
* Execution must be kept on the server side.
