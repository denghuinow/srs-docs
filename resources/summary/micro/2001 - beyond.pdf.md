**Purpose & Scope**: Summarize progress and clarify the approach for developing second prototypes across multiple application domains (Public, Home, Vetronics, Avionics) within the BEYOND project.

**Core Functions**:
*   Provide multimodal user interfaces for public information terminals.
*   Enable off-line authoring and editing of user interfaces for consumer and vetronics systems.
*   Implement an intelligent, adaptive flight deck to assist pilots.

**Key Constraints**:
*   System must avoid failures and dead ends in user dialogs.
*   Architectural redesign required to support component-based or plug-in extensibility.
*   Adaptations must leave the pilot in command and be non-intrusive.
