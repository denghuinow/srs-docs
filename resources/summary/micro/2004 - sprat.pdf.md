**Purpose & Scope**: A tool to assist analysts in mining, reconciling, and managing goals and scenarios from privacy and security policy documents.

**Core Functions**:
* Manage user access with defined roles (Administrator, Project Manager, Analyst, Guest).
* Add, classify, and manage goals and scenarios within a repository.
* Support access control policy specification and analysis (RACAF).

**Key Constraints**:
* The system must generate an access log for every add, delete, and edit action.
* Passwords must be stored securely in the database.
* User login must be secure.
