**Purpose & Scope**
A distance learning system for NJIT to enable effective professor-student communication via a secure application platform.

**Core Functions**
*   Provide real-time text, audio, and video communication between users.
*   Enable file hosting, management, and document collaboration.
*   Administer and submit online tests.

**Key Constraints**
*   The system must support only Internet Explorer, Mozilla Firefox, and Safari browsers.
*   The system must support only Windows XP, Vista, or Mac OS for client users.
*   System rollouts and validation must be scheduled during periods of low usage.
