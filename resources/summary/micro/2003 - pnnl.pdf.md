**Purpose & Scope**: Software to automatically detect and identify operational faults in HVAC chiller and cooling tower subsystems using sensed and fixed data, for use by building operators and service technicians.

**Core Functions**:
* Detect and identify specific performance and operational faults in chillers and cooling towers.
* Input and validate sensed data from real-time acquisition devices or batch files.
* Display and permanently store diagnostic results with fault description, cause, location, and time.

**Key Constraints**:
* Initial version is restricted to Microsoft Windows-compatible operating systems.
* Diagnostic processing requires all input data; algorithms will not run with missing data.
* The software design must support the future addition of diagnostic algorithms for other HVAC subsystems.
