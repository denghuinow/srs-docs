# Short Summary: Get Real Website Requirements

## Background and Objectives
The Get Real website aims to attract and encourage Oregon high school students to pursue computer science (CS) degrees within the Oregon University System. The primary goal is to increase the number of CS graduates by providing a teen-friendly, engaging platform with relevant career and educational information.

## In Scope
- Redesign existing pages (e.g., Exploring College, Jobs & Money, Real People) to improve visual appeal and navigation.
- Add new sections such as High School Courses, Search functionality, and Professional Organizations.
- Incorporate multimedia elements like video profiles to showcase CS professionals.
- Ensure the site is accessible and tested on major web browsers (IE, Firefox, Netscape).
- Implement features to track site usage and evaluate effectiveness over time.

## Out of Scope
- Development of user documentation for the website.
- Integration with specialized hardware or software interfaces.
- Creation of a comprehensive knowledge base for version 3.
- Expansion to include detailed community and private college listings beyond initial determination.
- Addressing unspecified security requirements beyond existing OUS site standards.

## Stakeholders and Core Use Cases
**Stakeholders:**
- **Web Designers:** Responsible for developing, testing, and maintaining the Get Real website.
- **Computer Science Task Force Subcommittee (ETIC):** Contributes to requirements and oversees project direction.
- **Oregon High School Students (Grades 9-12):** Primary users seeking information on CS careers and education.
- **OUS Campuses:** Provide CS program details and resources featured on the site.
- **High School Counselors:** Indirect users who may refer students to the site for career guidance.
- **Chancellor’s Office:** Hosts the site and provides institutional support.

**Core Use Cases:**
1. As a high school student interested in CS, I want to explore real-life profiles of CS professionals so that I can understand diverse career opportunities.
2. As a college-bound student unsure about CS, I want to view engaging, visually appealing content so that I can be encouraged to consider a CS career.
3. As a student, I want to search for internal and external CS-related information so that I can efficiently find relevant resources.
4. As a student considering multiple majors, I want to learn about the value of a CS minor so that I can see its application in other fields like medicine or law.
5. As a web designer, I want to track site hits and user engagement so that I can make data-driven improvements to content and design.
6. As a student, I want to access recommended high school courses for CS so that I can adequately prepare for university-level coursework.

## Success Metrics
- Increase in site traffic and time spent on pages, indicating higher engagement.
- Positive feedback from user testing with high school students on improved design and usability.
- Growth in the number of Oregon students enrolling in CS programs at OUS campuses.

## Major Constraints
- Limited availability of Chancellor’s Office resources for development and maintenance.
- Bandwidth limitations for streaming video content on the site.
- Need to adhere to OUS site design conventions and security standards.
- Requirement to prioritize changes based on feedback from two distinct student user groups.
- Dependence on external content sources (e.g., RSS feeds, professional organizations) that require ongoing curation.

## Undecided Issues
- Extent of inclusion for community and private colleges in the Exploring College section.
- Specific implementation details for the "Ask a Grad or Prof – FAQ" feature (e.g., blog format vs. static Q&A).
- Selection and prioritization of new page ideas beyond the proposed list.
- Allocation of weekly hours for web design resources to manage RSS feed editing.
- Final determination of which external career information sites to reference or link to.
