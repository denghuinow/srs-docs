# Short Summary: Black Start Capability Plan (BCP)

## Background and Objectives
The Black Start Capability Plan (BCP) ensures the CAISO grid has sufficient, properly located Black Start generators to restore power after a major blackout. Its objective is to establish a reliable system restoration capability through planning, testing, and coordination in alignment with WECC and NERC requirements.

## In Scope
*   Annual planning to verify the quantity, size, availability, and location of Black Start units meet WECC restoration requirements.
*   Mandatory periodic testing (simulation or operational) for designated Black Start units to validate self-start and grid-support capabilities.
*   Maintaining a database of all designated Black Start generators, including their capacity, test status, and location.
*   Annual training for CAISO Real-time Grid Operators on system restoration procedures and Black Start unit coordination.
*   Establishing and managing contracts (RMR and Interim) with generators to secure Black Start services.

## Out of Scope
*   Generators that can only safely reject load down to their auxiliary load (a different form of Black Start aid).
*   Detailed operational processes for executing a system restoration during an actual event.
*   Specific technical designs for generator protection or control systems.
*   Day-to-day market operations and scheduling outside of test scenarios.
*   Environmental or safety compliance procedures for generator operations.

## Stakeholders and Core Use Cases
*   **CAISO Grid Planners**: Determine required Black Start capacity and location through contingency studies and annual planning evaluations.
*   **CAISO Real-time Operators (Dispatcher)**: Execute Black Start tests and coordinate restoration using designated units during an event.
*   **Generator Owners/Operators (RMR/Interim/Voluntary)**: Maintain and demonstrate their unit's Black Start capability through testing as required.
*   **CAISO Operations Support Test Administrator**: Administers the Black Start testing process, analyzes results, and updates unit availability records.
*   **WECC/NERC**: Review and audit CAISO's Black Start plans, documentation, and test results for regional reliability compliance.
*   **Transmission Owners (PTOs)**: Coordinate on cranking paths and system restoration plans with the CAISO.

**Core User Stories:**
1.  As a **CAISO Grid Planner**, I want to conduct annual contingency studies so that the Black Start resources are sufficient and correctly located for system restoration.
2.  As a **CAISO Real-time Dispatcher**, I want to dispatch a Black Start test for an RMR unit so that its operational readiness can be verified.
3.  As a **Generator Owner**, I want to perform and document a Black Start test every five years so that my unit maintains its certified status with the CAISO.
4.  As the **CAISO Test Administrator**, I want to receive the Black Start test results and ambient temperature data so that I can accurately calculate and record the unit's availability.
5.  As a **WECC Auditor**, I want to request and review CAISO's Black Start test documentation so that I can verify compliance with regional reliability standards.
6.  As a **CAISO Operator**, I want to participate in annual restoration training and simulations so that I am prepared to execute the Black Start plan during an emergency.

## Success Metrics
*   **100% compliance** with the requirement to annually verify that Black Start resources meet WECC restoration plan needs.
*   **Successful testing** of at least one-third of all RMR and Interim Black Start units annually, as requested by the CAISO.
*   **Annual completion** of system restoration training for all Real-time Grid Operators, including simulation exercises.

## Major Constraints
*   Black Start tests for hydroelectric units cannot be requested during periods of constrained water availability.
*   Units must meet strict start-up and synchronizing time limits based on their technology (e.g., 30 minutes for hydro/gas turbines, 2.5 hours for hot steam turbines).
*   Testing must not endanger personnel, damage equipment, harm the environment, or violate any laws or operating limits.
*   The plan and its associated database must be reviewed and updated at least every five years.
*   Generator owners must submit test failure explanations and correction plans to the CAISO.

## Undecided Issues
*   The specific percentage of Black Start units expected to fail to start during a restoration event (to be determined by the CAISO for studies).
*   Start time limits for Black Start facilities using unspecified technologies or located in another reliability coordinator's area are subject to negotiation.
*   The full implementation schedule for using a system simulator for operator training is dependent on simulator availability.
