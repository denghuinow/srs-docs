**Short Summary**

**Background and Objectives**  
The HATS-GUI is a platform-independent graphical user interface for the High Assurance Transformation System (HATS), designed to simplify user interaction with transformation-based software development. Its objectives are to make HATS more user-friendly, increase its adoption within the research community, and provide intuitive management, execution, and visualization of program transformations.

**In Scope**  
- Management of applications (creation, deletion, modification, and file associations).  
- Parsing of transformation language programs and target files into syntax derivation trees (SDTs).  
- Execution of transformation language programs to apply transformations.  
- Display and manipulation of SDT and pretty-printed text outputs.  
- Configuration of application settings, including editor associations and SDT display properties.

**Out of Scope**  
- Direct application of transformations (handled by HATS-SML).  
- Multi-user support (single-user only).  
- Extensive help systems (assumes user expertise).  
- Modification of HATS-SML core functionality.  
- Support for operating systems beyond Sun Solaris, Windows 2000, and Linux.

- **End Users**: Experts in transformation-based software development who utilize HATS for high-assurance program transformations.

**User Stories**  
1. As a user, I want to create and configure applications so that I can manage transformation projects efficiently.  
2. As a user, I want to parse transformation language programs and target files so that I can generate SDTs for execution.  
3. As a user, I want to execute transformation language programs so that I can apply transformations to target files.  
4. As a user, I want to view and navigate SDT outputs so that I can analyze transformation results.  
5. As a user, I want to display and search pretty-printed text outputs so that I can review formatted transformation results.  
6. As a user, I want to associate editors with file types so that I can edit application files with preferred tools.

**Success Metrics**  
- The GUI displays an SDT with 10,000 nodes within five seconds.  
- The system operates correctly on Sun Solaris, Windows 2000, and Linux without code modification.  
- Users can perform transformations and view outputs without system halts due to HATS-SML errors.

**Major Constraints**  
- Implemented in Java 1.3 for platform independence.  
- Must avoid algorithms causing excessive memory usage (e.g., virtual window zooming for SDT display).  
- Requires Java Virtual Machine (JVM) and ML interpreter pre-installed on the host system.  
- Dependent on HATS-SML version 2.0 for transformation services.  
- Completed by December 2001.

**Undecided Issues**  
- Handling of extreme cases where pretty-printed text does not correspond to SDT terminal nodes.  
- Optimization strategies for SDT search algorithms beyond O(n²) complexity.  
- Specific error recovery mechanisms for HATS-SML process failures.  
- Detailed user interface layouts for configuration menus.  
- Long-term maintenance and update plans post-delivery.
