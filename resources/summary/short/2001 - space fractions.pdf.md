# Short Summary: Space Fractions

## Background and Objectives
Space Fractions is a web-based, interactive educational game designed to improve fraction-solving skills for sixth-grade students. The project also includes a "Math Umbrella" menu system to organize and link to other related math games.

## In Scope
- An introductory movie setting up the game's storyline.
- A main menu with help section and team information.
- A game sequence with multiple-choice fraction questions forming an adaptive storyline.
- An ending scene displaying the user's score and plot conclusion.
- A question updater tool for administrators to modify game content.

## Out of Scope
- Keyboard input (all interaction is via mouse clicks).
- Permanent file storage on the user's computer.
- Dependence on other software besides a web browser with Flash.
- New hardware requirements.
- Multi-user interaction within a single game instance.

## Stakeholders and Core Use Cases
**Stakeholders:**
- **Ms. Andrea Brooks (Client/Teacher):** The client from Pecan Springs Elementary who requested the software to aid in teaching fractions.
- **Sixth-Grade Students (End Users):** The primary users who will play the game to learn and practice fractions.
- **Game Administrator (e.g., Teacher Claire):** Responsible for updating game questions via the web-based tool.
- **The Denominators (Development Team):** The student team responsible for designing, developing, and maintaining the software.
- **Dr. Vicki L. Almstrum (Professor):** Provides academic oversight for the S2S (Student to Student) project.
- **Mr. Keith Henning (Team Mentor):** Offers technical guidance and support to the development team.

**Core Use Cases:**
1. As a sixth-grade student, I want to watch an introductory movie so that I understand the game's storyline and objectives.
2. As a competitive student (Bobby), I want to answer fraction questions quickly and see my score so that I can compete and excel.
3. As a student less comfortable with computers (Alice), I want to access a help section from the main menu so that I can understand the game rules easily.
4. As a teacher (Claire), I want to update the game's fraction questions via a web form so that I can customize the content for my class.
5. As a user, I want to receive feedback after each question so that I know if my answer was correct or incorrect.
6. As a user, I want to see a final score and story conclusion at the end so that I can gauge my performance and be encouraged to try again.

## Success Metrics
- The game is accessible and functional on any Internet-connected computer with a web browser supporting Flash 5.
- Students demonstrate improved fraction-solving skills after using the game.
- The question updater tool allows administrators to easily modify game content without technical assistance.

## Major Constraints
- The game must run within a web browser with Macromedia Flash 5 and JavaScript support.
- All user input must be accomplished via mouse clicks; no keyboard input is allowed.
- The total size of Flash movies must be optimized for download via a modem connection.
- The product must be maintainable, with code structured for easy future alterations.
- The interface must be graphically oriented and appealing to sixth-grade students.

## Undecided Issues
- Specific details of the adaptive storyline and how "critical points" precisely alter the plot.
- Exact number and difficulty distribution of fraction questions in the game sequence.
- Final design and organization of the "Math Umbrella" linking system.
- The specific security mechanism for the administrator's password in the question updater.
- The exact criteria for the customized score messages in the ending scene.
