**Purpose & Scope**: The system is a regional Center-to-Center (C2C) communications network for the Dallas/Ft. Worth area. It provides a common repository for traffic data and enables the exchange of device control information between Traffic Management Centers (TMCs) and other agencies.

**Core Functions**:
*   Collect, store, and share standardized traffic data (roadway networks, conditions, incidents, lane closures).
*   Transmit status and enable remote command/control of various ITS field devices (e.g., Dynamic Message Signs, Lane Control Signals, CCTV cameras).
*   Provide a web-based graphical map to display traffic conditions and incident data.

**Key Users**: Traffic Management Centers (TMCs) within the region; agencies without a formal TMC requiring access to traffic data and device control.

**Key Constraints**: The system must use ITS standards, specifically the Traffic Management Data Dictionary (TMDD) and DATEX/ASN message sets over TCP/IP. It must operate in a Microsoft Windows NT environment.
