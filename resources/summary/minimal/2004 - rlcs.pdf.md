**Purpose & Scope**: The system opens and closes the I-15 reversible lanes for peak traffic hours and special events, replacing an aging system. It interfaces with new field hardware controllers and devices.

**Core Functions**:
* Monitor and control the status of all field devices (e.g., gates, pop-up barriers, signs).
* Execute stored sequences to open or close lane entrances in a defined, safe order.
* Provide a graphical user interface for operators to view system status and issue commands.

**Key Users**: Operator, Management, Field Maintenance Staff, System Administrator.

**Key Constraints**:
* A catastrophic safety failure occurs if an entrance is opened for one direction while an entrance for the opposite direction is open.
* The system must be available 24 hours per day, 7 days per week.
* The software must operate on a hardware platform compatible with specified operating systems.
