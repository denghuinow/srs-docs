**Purpose & Scope**
The system is a national network for tracking crime and criminals to improve police investigation and detection outcomes. It provides centralized software for police stations to manage cases and interface with courts and citizens.

**Core Functions**
*   Register and manage crime complaints from citizens.
*   Support and document the police investigation process.
*   Record court interactions and manage prosecution case details.
*   Enable search for cases, persons, and property using basic and advanced criteria.
*   Provide an interface for information exchange between citizens and police.

**Key Users**
*   Police personnel, especially investigation officers and records staff.
*   Citizens.

**Key Constraints**
*   The system must maintain a complete, unalterable audit trail of all actions on critical entities like cases.
*   Access to cases must be restrictable to specific users or groups, with role-based control.
*   The system must be available during specified daily and weekly hours, with limits on planned and unplanned downtime.
*   Search operations must return result lists within 5-15 seconds, and case retrieval within 5-20 seconds, regardless of data volume.
*   The system must work in an offline mode for critical functionality.
