**Purpose & Scope**: PeaZip is a cross-platform file and archive manager application that provides a graphical user interface for multiple open-source archiving and compression utilities. Its scope is to allow users to create, update, and extract archives, and to provide related file management tools.

**Core Functions**:
*   Create and update compressed archives in various supported formats.
*   Extract the contents from compressed archives.
*   Provide file management utilities including secure deletion, file splitting/joining, and checksum calculation.
*   Apply two-factor authentication (password and keyfile) to archives.

**Key Users**: Any user of a computer system, including those with prior experience using archive managers and those without.

**Key Constraints**:
*   Must be compatible with 64-bit and 32-bit Microsoft Windows, and all POSIX (Linux, BSD, UNIX-like) operating systems.
*   Requires an x86-compatible CPU.
*   The software is licensed under LGPL.
*   The drag-and-drop feature from the application to the system is only supported on MS Windows.
