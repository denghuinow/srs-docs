**Purpose & Scope**: The system provides automated spatial and temporal tracking and analysis of water use permit data to support the Southern Water Use Caution Area (SWUCA) Management Plan and rule validation. It covers the entire District but is built to support SWUCA efforts.

**Core Functions**:
*   Provide spatial visualization and analysis of water use permit data via maps.
*   Track changes in permitted quantities, use types, ownership, and lapsed quantities.
*   Analyze and report on net benefit calculations for permit changes impacting Minimum Flows and Levels.
*   Aggregate permitted and actual water use data for user-defined geographic areas.
*   Monitor permit compliance based on submitted pumpage and condition data.

**Key Users**: Water Use Permit Evaluators, Technical Services Staff, Records and Data Staff, External Customers (e.g., public, local governments).

**Key Constraints**:
*   The system is dependent on data from existing Regulatory, GIS, and Water Management databases; changes to these sources must be coordinated.
*   The system must be developed within the District's current hardware and software architecture.
*   Some required data (e.g., lapsed quantities) is not currently available in source systems and may need to be implemented within this application.
