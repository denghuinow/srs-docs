**Purpose & Scope**
The system simulates Gaia mission catalog and main database data, including statistically equivalent final data, without using actual telemetry or the main ESAC database, for use by CU2 members involved in its design and construction.

**Core Functions**
*   Generate simulated data from a Universe Model or a user-provided object catalog.
*   Compute epoch observation data (e.g., astrometry, photometry, radial velocity per transit).
*   Compute combined data by aggregating epoch data (e.g., parallax, proper motions, mean values).
*   Simulate spectra (RP/BP and RVS) with applicable noise models.

**Key Users**
Members of Coordination Unit 2 (CU2).

**Key Constraints**
*   Output data formats must comply with the Universe Model and Main Database Interface Control Documents.
*   The system must process one complete source within two CPU seconds.
*   The system is a standalone Java application that must run on Linux, UNIX, and Mac platforms.
