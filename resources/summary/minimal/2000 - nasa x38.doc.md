**Purpose & Scope**
The system provides fault-tolerant software services for NASA's X-38 Crew Return Vehicle's quad-redundant Flight Critical Computer (FCC). It acts as an interface between the vehicle's application software and the underlying hardware/operating system.

**Core Functions**
*   Manage system redundancy and recovery from hardware faults in processors, network elements, and links.
*   Schedule and execute application tasks in deterministic 50 Hz, 10 Hz, and 1 Hz rate groups.
*   Provide fault-tolerant synchronous and immediate message-passing communication services between tasks and processors.
*   Detect, isolate, and report hardware faults via continuous built-in testing.
*   Manage and align congruent memory across redundant processors during recovery.

**Key Users**
*   Flight Critical Processors (FCPs) operating as a redundant set.
*   Instrument Control Processors (ICPs) operating as simplex units.

**Key Constraints**
*   The system must be two-fault tolerant for non-simultaneous hardware faults.
*   Critical operations, such as fault isolation and scheduler overhead, have defined maximum execution times (e.g., 3 ms, 1 ms).
*   The software must execute on the Radstone Power PC 604R hardware using the VxWorks 5.4 operating system and the C programming language.
*   The software and operating system together must not exceed defined memory limits (e.g., 3 MB ROM, 9 MB DRAM).
