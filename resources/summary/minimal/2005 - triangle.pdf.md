**Purpose & Scope**: The system is an application for playing various combinatorial triangulation games as solitaire, against computer AI, or with another player. It also functions as a platform for defining new types of triangulation games without modifying the core software code.

**Core Functions**:
*   Provides a graphical user interface operable with mouse and keyboard.
*   Supports multiple, user-selectable triangulation games.
*   Allows games to be defined externally in files separate from the software code.
*   Supports players being either human or computer AI, including a default random AI.
*   Loads and saves game states to files.

**Key Users**: Players and game developers.

**Key Constraints**: The software must be implemented in Java, run on any system with Java Runtime Environment 1.4 or later, and must not depend on platform-specific libraries.
