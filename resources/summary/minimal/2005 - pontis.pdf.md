**Purpose & Scope**: Pontis 5.0 is a bridge management system that provides data management, condition assessment, preservation modeling, needs analysis, and reporting for transportation agencies. It replaces the existing Pontis 4.x product line with a web-enabled application while preserving agency investments.

**Core Functions**:
- Manage bridge inventory and inspection data (create, edit, and calculate derived ratings).
- Develop preservation models (update deterioration probabilities and action costs).
- Perform program simulations to generate network-level work recommendations and bridge-level analysis.
- Develop and manage projects and programs (create, edit, and assign work items).

**Key Users**:
- Inspectors (collect and validate field data).
- Bridge engineers and planners (perform analysis, modeling, and project planning).
- Highway program planners (integrate bridge projects into broader programs).
- System administrators (manage users, roles, and system configuration).

**Key Constraints**:
- Must be developed using Microsoft .NET technologies and support Internet Explorer and Windows XP.
- Must maintain consistency with the existing Pontis 4.x application and BRIDGEWare database design.
- Must support specific relational database management systems (Sybase Adaptive Server Anywhere, Oracle, Microsoft SQL Server).
- Must integrate with other BRIDGEWare products and support GIS interaction.
