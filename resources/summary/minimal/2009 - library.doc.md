**Purpose & Scope**: The system shall provide enhanced management reporting and analysis tools for the PINES library consortium, operating within and extending the existing Evergreen Integrated Library System (ILS).

**Core Functions**:
* Provide a user-friendly query tool and configurable report templates for staff.
* Support fine-grained permissions for report creation, cloning, and data access.
* Generate pre-defined and ad-hoc reports for inventory, patron demographics, transactions, and financial auditing.
* Analyze collection use, branch capacity, and patron behavior.
* Manage and report on item transfers, purging, and inventory status.

**Key Users**: Staff, Library Managers, Library Directors, Local System Administrators, Global System Administrators.

**Key Constraints**: Must operate on a Linux/Solaris server; accessible via web browser or Windows client; must use a relational database; must comply with standard accounting and auditing practices; must support a consortium of 286 locations.
