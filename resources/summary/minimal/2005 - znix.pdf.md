**Purpose & Scope**: The system provides an application-independent framework for retrieving and manipulating user information through a centralized store and hierarchical view. It applies to the high-level design of the ZNIX Framework.

**Core Functions**:
- Maintain a centralized archive for user information.
- Provide a hierarchical model for managing archived information.
- Allow users to add, remove, modify, or back up information without disrupting the hierarchy.
- Provide a public API for client applications to interact with the Framework.

**Key Users**: Home users, managerial staff, executives, and researchers with basic IT skills.

**Key Constraints**:
- Must run on an Intel Pentium III 1-GHz PC with 256 MB RAM.
- Framework shell must not use more than 40 MB of RAM.
- Must be licensed under LGPL for the framework and GPL for accompanying tools.
- Must guard against malicious scripts and unintended user corruption of information.
