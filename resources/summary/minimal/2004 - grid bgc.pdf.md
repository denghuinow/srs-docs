**Purpose & Scope**: The system is a grid-based software infrastructure for bio-geochemical modeling, providing a web portal interface for managing data, running simulations, and handling output for the Daymet and Biome-BGC models.

**Core Functions**:
*   Execute Daymet model runs.
*   Execute BiomeBGC model runs.
*   Manage and organize input/output data objects and projects.
*   Visualize and download output data.

**Key Users**: Scientists (primary users), Portal Administrators.

**Key Constraints**:
*   Must use the Globus toolkit.
*   Must comply with NCAR security policies.
*   Must use the NCAR Mass Storage System for all file storage.
*   Users must have a valid NCAR Gatekeeper account.
