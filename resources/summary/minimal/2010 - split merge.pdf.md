**Purpose & Scope**: The system is a free, open-source tool for splitting, merging, and manipulating PDF documents. It provides a graphical user interface and a command-line console for these operations.

**Core Functions**:
*   Split a single PDF document using various criteria (e.g., by page ranges, bookmarks, file size).
*   Merge multiple PDF documents or extract page ranges into a single document.
*   Mix pages alternately from two PDF documents.
*   Rotate pages within PDF documents.
*   Visually reorder, rotate, or delete specific pages from a PDF document.

**Key Users**: General users needing PDF manipulation, and open-source software developers/contributors.

**Key Constraints**: The software must run on a Java Virtual Machine (version 1.6 or higher). It is licensed under the GNU GPLv2. The application must not modify the original input PDF files.
