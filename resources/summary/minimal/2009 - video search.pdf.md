**Purpose & Scope**: The system is a video search engine that searches multiple websites for streaming videos and torrents with a single query to reduce user search time.

**Core Functions**:
*   Search a database of torrent websites and return results with metadata.
*   Search a database of video streaming websites (both host and link sites) and return results.
*   Allow users to filter searches by type (torrent, stream host, stream link).
*   Allow users to sort search results by various criteria.
*   Allow system developers to update the databases of searchable websites.

**Key Users**: General end-users and system developers.

**Key Constraints**:
*   Must be portable across specified operating systems (Windows XP/Vista, Mac OS X, Linux) and web browsers.
*   A query to any website must take no longer than 5 seconds.
*   The system must not host any video content.
