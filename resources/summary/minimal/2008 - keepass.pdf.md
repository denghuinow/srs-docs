**Purpose & Scope**: The system securely stores user passwords and related data in an encrypted database, locked by a single master password or key file. It is a portable application for personal password management.

**Core Functions**:
*   Create, open, and save the encrypted password database.
*   Add, view, edit, and delete password entries organized within groups.
*   Generate random passwords for new entries.
*   Search the database for specific entries.

**Key Users**: End users/desktop users, system administrators, and advanced end users.

**Key Constraints**:
*   A copied password is cleared from the clipboard after 10 seconds.
*   The database cannot be recovered if the master password or key file is lost.
