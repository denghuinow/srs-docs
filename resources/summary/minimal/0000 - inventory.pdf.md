**Purpose & Scope**
The system integrates inventory databases from three university faculties into a unified web interface for centralized management. Its scope covers the tracking, transfer, and reservation of university assets (rooms, software licenses, other assets) across a defined organizational hierarchy.

**Core Functions**
*   Manage assets (add, edit, modify, transfer).
*   Create and approve requests to borrow assets or reserve spaces.
*   Manage user permissions based on administrative roles.

**Key Users**
University Administrators, Faculty Administrators, Department Administrators, IT Administrators, and general Users (students, professors).

**Key Constraints**
The system must be available during working hours, run on both Microsoft and Unix platforms, authenticate all users, and terminate database queries exceeding one minute.
