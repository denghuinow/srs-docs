**Purpose & Scope**: Provides a platform-independent graphical interface to simplify user interaction with the High Assurance Transformation System (HATS), enabling users to construct and apply program transformations. The system manages applications, orchestrates parsing and execution via HATS-SML, and displays transformation outputs.

**Core Functions**:
1. Manage applications (create, store, retrieve, modify files and associations).
2. Parse transformation language programs and target files into Syntax Derivation Trees.
3. Execute transformation language programs on target files.
4. Examine and navigate transformation outputs (SDTs and pretty-printed text).

**Key Users**: Domain experts and researchers knowledgeable in transformations and formal methods; computer-savvy users familiar with hierarchical file systems and software tools.

**Key Constraints**:
* Must be platform-independent and run on Sun Solaris, Windows 2000, and Linux.
* Must be implemented in Java.
* Must be completed by December 2001.
* Requires an installed Java Virtual Machine and ML interpreter.
