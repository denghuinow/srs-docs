**Purpose & Scope**: The system provides operational control and data acquisition for the Gemini 8m Telescopes to acquire astronomical data. It defines requirements for the control system software, excluding commercial packages and embedded software without interfaces.

**Core Functions**:
*   Support remote operations, including observing, control, monitoring, and diagnostics.
*   Execute queue-based and service observing via automated, pre-programmed sequences.
*   Control and coordinate multiple telescope subsystems and scientific instruments.
*   Acquire, store, compress, and transfer astronomical and engineering data.

**Key Users**: Astronomer, Science Observer, Telescope Operator, Support personnel, Developer, Administrator.

**Key Constraints**:
*   Software must be hardware-independent and portable where possible.
*   Commercial packages, public domain software, and established standards must be used when feasible.
*   The system must support all defined observing modes and remote operations from inception.
