**Purpose & Scope**: The system is a graphical partition editor for creating, reorganizing, and deleting disk partitions. It operates as a LiveCD application that runs at system boot without installation.

**Core Functions**:
* Create, delete, and format partitions.
* Resize or move partitions while preserving data.
* Copy and paste partitions.

**Key Users**: Casual users, developers, testers, and documentation writers.

**Key Constraints**: The system depends on GNU libparted and external file system tools to perform operations. It does not support Logical Volume Management (LVM).
