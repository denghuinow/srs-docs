**Purpose & Scope**
The system is a plug-and-play web store for online sales, deployed on a USB key. It manages customer accounts, inventory, shopping carts, and order confirmations, with an initial inventory capacity of 100 items expandable to 20,000.

**Core Functions**
* Manage customer accounts (creation, login, profile storage).
* Manage product inventory (categorization, addition, deletion, updates).
* Process customer purchases (shopping cart, checkout, payment, order confirmation).
* Provide a web-based interface for browsing and searching products.
* Support extensibility via a documented plug-in API.

**Key Users**
* System Administrator.
* Sales Personnel.
* Customer.

**Key Constraints**
* Must operate on specified browsers: Microsoft Internet Explorer 6/7 and Netscape Communicator 4/5.
* Must use an SQL-based database.
* Must run on a specific Intel-based system with Slackware Linux 2.6 and Apache.
* Hardware is a provided USB key from Yoggie Corporation.
