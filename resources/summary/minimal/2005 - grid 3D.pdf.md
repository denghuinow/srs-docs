**Purpose & Scope**: The system visualizes biological data in a three-dimensional environment to allow investigation and comparison of data attributes. It processes user-supplied data files to generate an interactive 3D plot.

**Core Functions**:
*   Plot data points in a 3D grid from a formatted input file.
*   Color points according to a cluster attribute from the data.
*   Allow user interaction to rotate, zoom, and move the grid.
*   Display point names and detailed information on user selection.

**Key Users**: Research scientists, data-mining scientists, and students investigating proteins.

**Key Constraints**:
*   Must be available on both Windows and Linux operating systems.
*   Application execution must be kept server-side.
*   Must be ready for a publication deadline in March 2005.
