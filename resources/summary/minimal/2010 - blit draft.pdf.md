**Purpose & Scope**: Rewrite the core Laboratory Information System (LIS) to improve performance and ensure system integrity, while retaining existing core functionalities. The project scope is limited to implementing critical enhancements and defects.

**Core Functions**:
* Administer system users, including creating users and assigning roles.
* Log system errors, warnings, and informational messages to an external file.
* Provide an online help system accessible from every user screen.

**Key Users**: Users with administrative privileges; general system users.

**Key Constraints**: The system must be developed using the .NET 3.5 platform and a single SQL Server 2008 database. It must comply with HIPAA standards. Updates to the production environment can only be scheduled on Tuesdays between 7pm and 7am.
