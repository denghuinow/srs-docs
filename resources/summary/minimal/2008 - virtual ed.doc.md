**Purpose & Scope**: The system is a distance learning platform for NJIT to enable effective professor-student communication via a secure application providing email, group chat, bulletin boards, and audio/visual tools.

**Core Functions**:
* Provide real-time instant messaging for one-to-one and group text communication.
* Enable live and on-demand streaming of audio and video for lectures and conferences.
* Provide file hosting and management tools for user storage and assignment submission.
* Support online testing with capabilities for students to download, complete, and upload exams.

**Key Users**: System Administrators, Administrative End Users (e.g., professors), and Limited End Users (e.g., students).

**Key Constraints**:
* The system must integrate with an existing NJIT user database that supports a maximum of 250 concurrent users.
* Development and deployments must accommodate low system downtime as the university is in session.
* Client-side functionality is limited to specific web browsers (Internet Explorer, Safari, or Firefox).
