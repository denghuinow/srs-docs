**Purpose & Scope**: The system facilitates ABC Paint's migration to a new paint numbering scheme by enabling conversion from old to new numbers. It is a standalone web-based application to be integrated into the existing ABC Paint website.

**Core Functions**:
*   Convert old paint numbers to new scheme numbers.
*   Search for paint colors by name, number, or value.
*   Select colors using a graphical interface.
*   Maintain a session-persistent palette of user-selected colors.
*   Administratively update, add, or delete paint data and manage users.

**Key Users**: Default users (customers/employees) and Administrative users (with three permission levels).

**Key Constraints**: The application must be web-based. The client requires a compatible web browser (e.g., Internet Explorer 4.01, Netscape 6.0, or Mozilla 1.0+). A pointing device is required for color selection. The server must process color search requests in sub-second time.
