**Purpose & Scope**: The system is an MHP (Multimedia Home Platform) application for TV that provides MSN Messenger functionality, allowing users to see online contacts and chat. It excludes file transfer and webcam support.

**Core Functions**:
*   User login with an existing .NET Passport account.
*   Manage and display user and contact presence status.
*   Send and receive instant text messages.
*   View the TV program a contact is watching.

**Key Users**: End-users.

**Key Constraints**: The system must use the .NET Messenger Service protocol (MSNPv8). It is an MHP xlet for a TV platform.
