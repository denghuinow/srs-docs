**Purpose & Scope**
The system is a web-based childcare center management application designed to automate administrative tasks, track child and family information, and manage billing and reporting to improve operational workflow.

**Core Functions**
*   Manage child enrollment, classroom assignments, and a waiting list.
*   Record child arrival/departure times and track late pickups for billing.
*   Maintain child records, including immunization dates and teacher comments.
*   Generate monthly invoices and predefined operational reports.
*   Provide a daily reminder system for employees.

**Key Users**
*   Administrators (full system access).
*   Teachers and Assistants (limited to entering child data and times).

**Key Constraints**
*   The system must have a web-based interface compatible with Internet Explorer and Netscape Navigator.
*   The system must respond to user requests within 20 seconds.
*   The system will be built using ASP.NET, requiring a compatible web server.
*   Each classroom has a maximum capacity of 20 children.
