**Purpose & Scope**: The system addresses smart grid interoperability challenges by managing information across business, application, data, and technical architectures. Its scope encompasses both smart grid and non-smart grid data.

**Core Functions**:
*   Share information models with external entities.
*   Manage data for smart grid and non-smart grid domains.
*   Incorporate and enable standards like the IEC Common Information Model.

**Key Users**: Business units, projects, and external entities.

**Key Constraints**: The system must support both smart grid and non-smart grid data, integrate the IEC Common Information Model, and address information security within all architectural components.
