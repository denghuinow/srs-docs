**Purpose & Scope**: The system is a prototype smart home management system for controlling a home's environment, security, and appliances via a web interface. Its scope is limited to managing temperature, humidity, security contacts, and appliance power states within a simulated environment.

**Core Functions**:
*   Monitor and set temperature for up to eight thermostats.
*   Monitor and set humidity for up to eight humidistats.
*   Manage a security system with up to fifty contact sensors and activate alarms.
*   Monitor and control the on/off state of up to one hundred appliances/lights.

**Key Users**: General home users and a DH Technician for setup and maintenance.

**Key Constraints**: The prototype must be completed within twelve months by a team of five engineers, developed for a simulated (not physical) environment, and must minimize component costs.
