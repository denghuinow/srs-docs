**Purpose & Scope**
The system is the ground data processing facility for the ASPERA-3 instrument on the Mars Express mission. It acquires, processes, archives, and distributes all ASPERA-3 and spacecraft orbit/attitude telemetry data.

**Core Functions**
*   Acquire ASPERA-3 and Mars Express orbit/attitude telemetry from the European Space Operations Centre.
*   Process all ASPERA-3 science, engineering, and ancillary data into Instrument Data File Set (IDFS) format.
*   Distribute IDFS data sets to the ASPERA-3 science team.
*   Provide web-based displays of data for public view and for science analysis.
*   Archive telemetry and IDFS data locally and submit validated IDFS data to the NASA Planetary Data System.

**Key Users**
*   The ASPERA-3 science team and Co-Investigators.
*   The public (for designated web displays).

**Key Constraints**
*   ASPERA-3 data must be submitted to the NASA Planetary Data System within 6 months of acquisition.
*   Electronically distributed IDFS data must be provided to Co-Investigators within 24 hours of error-free telemetry acquisition.
*   Science analysis web displays must be password protected until data is made public.
*   The system must operate on specified UNIX-based production and development computers.
