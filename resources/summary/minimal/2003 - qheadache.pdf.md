**Purpose & Scope**
The system is a computerized puzzle game where players move blocks on a board to solve a specific puzzle. It is a standalone application with a graphical user interface.

**Core Functions**
*   Manually select, deselect, and move blocks within a defined game board area.
*   Undo and reo the last thousand player actions.
*   Track and display game statistics including move count and elapsed time.
*   Save and load game state to/from a file.
*   Maintain a persistent top-ten score list.

**Key Users**
Users are players with basic computer operation skills, starting from age 8.

**Key Constraints**
*   Must be built using the Qt graphical library.
*   Must run on all operating systems supported by Qt.
*   Requires a minimum screen resolution of 800x600 pixels.
*   Supports only one user per machine instance.
