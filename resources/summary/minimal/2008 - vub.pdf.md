**Purpose & Scope**
The system manages a database of bibliographic information and full-text publications, accessible via web and command line interfaces. It automatically extracts metadata from uploaded documents and provides search, access control, and user management.

**Core Functions**
*   Search and download publications.
*   Upload publications with automatic extraction of bibliographic metadata.
*   Manage user accounts and permissions.
*   Manage groups and system configuration.

**Key Users**
Guest, VUB-Network User, Member, Publisher, Moderator, Administrator.

**Key Constraints**
*   Must run on the Linux-based Wilma server.
*   Must be implemented in Ruby without using frameworks.
*   Web interface must comply with W3C XHTML 1.0 Transitional standard.
*   Must follow specific object-oriented design and coding conventions.
