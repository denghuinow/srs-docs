**Purpose & Scope**
A web-based game to improve sixth-grade students' fraction-solving skills, providing score feedback and an umbrella menu system for accessing multiple math games.

**Core Functions**
*   Presents a sequence of multiple-choice fraction questions within a storyline.
*   Allows an administrator to update game questions via a web interface.
*   Provides a menu (umbrella) linking to other related math learning games.
*   Displays an introductory movie and a main menu.

**Key Users**
Sixth-grade students and their teacher.

**Key Constraints**
*   Must run in a web browser with Macromedia Flash 5 and JavaScript support.
*   All user input must be via mouse clicks; no keyboard input.
*   Must be accessible over the Internet.
*   Game questions must be updatable via a web-based administrative interface.
