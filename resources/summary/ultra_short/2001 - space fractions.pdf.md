**Purpose & Scope**
The system is a web-based, interactive game to improve fraction-solving skills for sixth-grade students. It provides a storyline-based quiz and a separate "umbrella" menu linking to other math games. It does not teach new concepts, require keyboard input, or run outside a web browser with Flash support.

**Product Background / Positioning**
The product is a standalone educational game requested by an elementary school teacher. It is part of a series of "Student to Student" (S2S) projects and will be hosted on the S2S website. It is not dependent on or a component of any other software.

**Core Functional Overview**
1.  Play an introductory movie to set up the game's storyline.
2.  Present a main menu with help and navigation options.
3.  Administer a series of multiple-choice fraction questions that form an adaptive storyline.
4.  Display an ending scene with the user's score and a story conclusion based on performance.
5.  Allow an administrator to update the game's questions via a web-based tool.
6.  Provide an umbrella menu linking to other related S2S math projects.

**Key Users & Usage Scenarios**
Primary users are sixth-grade students and their teacher. Students play the game to answer fraction questions within a story, receiving a score at the end. The teacher acts as an administrator to update the game's question bank via a separate, password-protected interface.

**Major External Interfaces**
The user interface is entirely graphical and mouse-driven, with no keyboard input. The software requires a web browser with the Macromedia Flash 5 plug-in. It interacts with a web server to host the game and store administrator-updated question files.

**Key Non-functional Requirements**
The product must run on any Internet-accessible computer with a web browser supporting JavaScript and Macromedia Flash 5. The main game movie must be 1-2 MB or less. The product's security is dependent on the host web browser's security.

**Constraints, Assumptions & Dependencies**
A critical dependency is that end-users must have a web browser with the Macromedia Flash 5 plug-in. The product is constrained to mouse-only input. It is assumed that users have basic computer and Internet skills.

**Priorities & Acceptance Approach**
The core priority is the functional game sequence for students. Maintainability for future updates is also a primary goal. Acceptance will be based on the game correctly presenting questions, scoring answers, and allowing administrative updates as specified.
