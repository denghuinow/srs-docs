**Purpose & Scope**
The system automates the opening and closing of reversible traffic lanes on the I-15 freeway for daily peak hours and special events. It replaces an aging control system and interfaces with new field hardware. It does not control freeway exits or accept operational input from external traffic systems.

**Product Background / Positioning**
This is a safety-critical traffic control system for the California Department of Transportation (Caltrans). It interfaces with external systems like ATMS and traveler information networks but operates on a private, secured network. It replaces a legacy system and must integrate with new field controllers and devices.

**Core Functional Overview**
1.  Provide a graphical user interface for operators to view status and issue commands.
2.  Monitor and control field devices (gates, pop-up barriers, lights, changeable message signs).
3.  Execute stored sequences for opening and closing the reversible lanes.
4.  Process and secure all system data, including user authentication and safety rules.
5.  Generate operational and maintenance reports.
6.  Validate all device control commands against safety rules to prevent catastrophic wrong-way openings.

**Key Users & Usage Scenarios**
*   **Operator:** Logs on at the Traffic Management Center (TMC) to command the system during normal mode. Only one operator can have command control at a time.
*   **Field Maintenance Staff:** Can execute control sequences from field workstations during maintenance mode only.
*   **Management / Systems Staff:** Can view reports and system status but cannot issue control commands.
*   **System Administrator:** Configures the system, including users, devices, and schedules.
*   **Typical Scenario:** An operator logs on, confirms a scheduled opening sequence, and the system sequentially opens entrance devices (e.g., gates, pop-up barriers, signs) for northbound traffic while ensuring all southbound entrances are closed.

**Major External Interfaces**
*   **External Data Feed:** A one-way output provides lane status (open/closed, customer eligibility) to external servers for systems like ATMS and traveler information.
*   **Remote Access:** A secure dial-in interface allows authorized users to connect to the RLCS network from outside.
*   **Field Hardware:** Interfaces with field device I/O cards and controllers (e.g., 2070 ATC) via driver software.

**Key Non-functional Requirements**
*   **Availability:** Must be operational 24/7/365. Yearly uptime must be at least 99.99%, with a recovery time of no more than 10 minutes after a failure.
*   **Performance:** The GUI and status displays must update within 2 seconds of a status change. Field devices must respond to commands within 12 seconds of operator confirmation.
*   **Reliability:** Must function continuously without a reset due to system error for at least 30 consecutive days. Implements redundant control capabilities for degraded operation.
*   **Safety/Security:** All control commands must be validated against safety rules stored in non-volatile memory at multiple system levels. Uses the MD5 algorithm for data and software integrity verification. User access is controlled by command level, device, mode, workstation, and function.

**Constraints, Assumptions & Dependencies**
*   **Constraint:** Wireless connections between field controllers are not allowed due to security and interference risks.
*   **Constraint:** The system must operate on a private communications network (fiber, copper) provided by Caltrans.
*   **Dependency:** Relies on the deployment of a fiber optic network along the I-15 corridor for primary communications.
*   **Assumption:** During deployment, the new system will be tested while the old system remains in place during facility closure hours.

**Priorities & Acceptance Approach**
All specified requirements are classified as "Must Have." The system will be delivered in a single release. Acceptance will involve demonstrating that the complete set of requirements is satisfied, including the execution of defined operational sequences and meeting all performance, reliability, and safety metrics.
