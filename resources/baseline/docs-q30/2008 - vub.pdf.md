## 1 Introduction

### 1.1 Purpose
This document specifies the requirements for the VUB Academic Publications Management System. It describes the functional and non-functional requirements, constraints, and interfaces for a system designed to manage academic publications for Vrije Universiteit Brussel (VUB) users.

### 1.2 Scope
The system will provide comprehensive management of academic publications including search, download, upload, and publication management capabilities for VUB faculty and students. 

**In-scope:**
- Publication search and retrieval
- User account management
- Publication upload with metadata extraction
- Multi-format export capabilities
- Role-based access control

**Out-of-scope:**
- External network access for unregistered users
- Audio/video file support
- Non-VUB network access for non-logged-in users
- Integration with external publication databases

### 1.3 Definitions, Acronyms, and Abbreviations
- **VUB**: Vrije Universiteit Brussel
- **CLI**: Command Line Interface
- **XHTML**: Extensible HyperText Markup Language
- **PDF**: Portable Document Format
- **PS**: PostScript
- **BIB**: Bibliography format
- **RIS**: Research Information Systems format

## 2 Overall Description

### 2.1 Product Perspective
The system is a standalone web application built on the Wilma server infrastructure (Linux/Ruby environment). It replaces manual publication handling processes and integrates with existing VUB network authentication systems and database infrastructure.

### 2.2 Product Functions
- **Publication Search**: Keyword, author, and date-based searching
- **Document Management**: Upload, download, and storage of academic publications
- **User Management**: Account creation, validation, and role assignment
- **Metadata Extraction**: Automatic bibliography information extraction from uploaded files
- **Export Capabilities**: BIB and RIS format exports for publication references

### 2.3 User Characteristics

| User Role | Primary Responsibilities | Technical Proficiency |
|-----------|--------------------------|----------------------|
| Guest | Register, validate account | Basic web navigation |
| VUB-Network User | Search, download publications | Basic web navigation |
| Member | Search, download, edit profile | Intermediate web usage |
| Publisher | Upload/edit own publications | File management skills |
| Moderator | Manage departmental publications, user levels | Advanced system knowledge |
| Admin | Full system administration | Expert technical skills |

### 2.4 Constraints
- **Platform**: Must run exclusively on Linux (Wilma server)
- **Implementation**: Ruby 1.8+ with no external libraries/frameworks
- **Access**: VUB network required for non-logged-in access
- **Authentication**: Integration with VUB network authentication systems

### 2.5 Assumptions and Dependencies
- Wilma server will maintain adequate uptime
- VUB network infrastructure remains stable
- MySQL database backend is available and properly configured
- Users have compatible browsers for XHTML 1.0 Transitional content

## 3 System Features

### 3.1 Publication Search Module

#### 3.1.1 Description
Enables users to search academic publications using various criteria.

#### 3.1.2 Functional Requirements
- **FR-001**: System shall allow search by keyword across publication titles and abstracts
- **FR-002**: System shall support author-based searching
- **FR-003**: System shall enable date-range filtering of publications
- **FR-004**: Search results shall be paginated for optimal performance

### 3.2 Publication Download Module

#### 3.2.1 Description
Manages downloading of publication files in supported formats.

#### 3.2.2 Functional Requirements
- **FR-005**: System shall allow single publication download
- **FR-006**: System shall support batch download of multiple publications
- **FR-007**: Download access shall be restricted based on user privileges

### 3.3 Publication Upload Module

#### 3.3.1 Description
Handles uploading of new publications with automatic metadata extraction.

#### 3.3.2 Functional Requirements
- **FR-008**: System shall accept PDF and PS file formats
- **FR-009**: Automatic bibliography extraction from uploaded files
- **FR-010**: Upload capability restricted to Publisher role and above
- **FR-011**: File validation for format and size constraints

### 3.4 User Management Module

#### 3.4.1 Description
Comprehensive user account and privilege management.

#### 3.4.2 Functional Requirements
- **FR-012**: Guest registration with email validation
- **FR-013**: Role-based access control (Guest → VUB-Network User → Member → Publisher → Moderator → Admin)
- **FR-014**: Admin capability to create/delete user accounts
- **FR-015**: Users can edit personal account details
- **FR-016**: IP-based authentication for VUB-network users

### 3.5 Publication Reference Module

#### 3.5.1 Description
Manages publication metadata and export capabilities.

#### 3.5.2 Functional Requirements
- **FR-017**: System shall display publication references
- **FR-018**: Export capabilities to BIB format
- **FR-019**: Export capabilities to RIS format
- **FR-020**: Moderators can edit departmental publications

## 4 External Interface Requirements

### 4.1 User Interfaces

#### 4.1.1 Web Interface
- **Technology**: XHTML 1.0 Transitional
- **Access**: Available to all user roles
- **Features**: Responsive design compatible with standard web browsers

#### 4.1.2 Command Line Interface (CLI)
- **Access**: Admin users only
- **Network**: VUB-network access required
- **Functionality**: System administration and bulk operations

### 4.2 Hardware Interfaces
- **Server**: Wilma server infrastructure
- **Storage**: Adequate disk space for publication repository
- **Network**: VUB internal network infrastructure

### 4.3 Software Interfaces
- **Database**: MySQL backend for data persistence
- **Authentication**: VUB network authentication system
- **Operating System**: Linux environment

### 4.4 Communication Interfaces
- **Protocol**: HTTP/HTTPS for web interface
- **Security**: Encrypted password transmission
- **Access**: Network-level restrictions for external access

## 5 Non-Functional Requirements

### 5.1 Performance Requirements
- **Search Response**: Search operations complete within 3 seconds for typical queries
- **Upload Processing**: File upload and metadata extraction within 30 seconds for standard documents
- **Concurrent Users**: Support for minimum 50 concurrent users

### 5.2 Security Requirements
- **SEC-001**: Passwords encrypted at rest using industry-standard hashing algorithms
- **SEC-002**: Passwords encrypted in transit using secure protocols
- **SEC-003**: Role-based access control enforced at all access points
- **SEC-004**: Session management with appropriate timeout periods

### 5.3 Reliability Requirements
- **Availability**: System available during Wilma server uptime
- **Data Integrity**: Database consistency maintained with no orphaned records
- **Error Handling**: Clear error messaging during system downtime

### 5.4 Software Quality Attributes
- **Maintainability**: Code modularity for ease of maintenance
- **Portability**: Limited to Linux Wilma server environment
- **Scalability**: Architecture supporting future user growth

## 6 Other Requirements

### 6.1 Development Constraints
- **Platform**: Exclusive deployment on Linux Wilma server
- **Language**: Ruby 1.8+ implementation
- **Dependencies**: No external libraries or frameworks permitted
- **Network**: VUB network integration required

### 6.2 Implementation Priorities

#### Phase 1 (Critical)
- Core search functionality
- Publication download capabilities
- Basic upload with metadata extraction
- Essential user management

#### Phase 2 (Enhanced)
- Advanced search filters
- Batch operations
- Extended export formats
- Moderator tools

### 6.3 Acceptance Criteria
- All critical functions operate per SRS specifications
- Database consistency verified through backup and recovery testing
- Role-based access control properly implemented
- Integration with VUB authentication system validated
